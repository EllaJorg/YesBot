# GitHub Pages Setup Instructions

This repository contains documentation in the `docs/` folder that should be published via GitHub Pages.

## Enable GitHub Pages

To enable GitHub Pages for this repository:

1. Go to the repository settings: https://github.com/lindsaygross/Alba/settings/pages
2. Under "Build and deployment":
   - **Source**: Select "Deploy from a branch"
   - **Branch**: Select `main` branch and `/docs` folder
   - Click "Save"

3. GitHub will automatically build and deploy your site

## Access Your Privacy Policy

Once enabled, your privacy policy will be available at:
- **Full site:** https://lindsaygross.github.io/Alba/
- **Privacy Policy:** https://lindsaygross.github.io/Alba/privacy

The site may take a few minutes to become available after enabling GitHub Pages.

## Files Structure

- `docs/privacy.md` - The privacy policy document
- `docs/index.md` - The landing page with links
- `docs/_config.yml` - Jekyll configuration for styling

## Note

The privacy policy is written in Markdown and will be automatically converted to HTML by GitHub Pages using Jekyll.
